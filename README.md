# AFLOW-src

This is the [Entropy for Energy Laboratory](https://entropy4energy.ai) fork of `aflow++`, maintained by [the team at Johns Hopkins University](https://entropy4energy.ai/team.html).

The code builds on the public AFLOW `3.2.14` release from [`aflow-org/aflow`](https://github.com/aflow-org/aflow) and is distributed under the GNU General Public License v3.0. See [`LICENSE`](LICENSE).

## Building

Build `aflow` from the repository root:

```bash
make -C src aflow
```

## Releases

Versions are tagged `v<AFLOW version>+s4e.<release>`, for example `v3.2.14+s4e.1`. Release changes are listed in [`src/README_AFLOW_VERSIONS_HISTORY.TXT`](src/README_AFLOW_VERSIONS_HISTORY.TXT), with contributor initials next to each change.
